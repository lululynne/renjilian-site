## 五个问题怎么解的

1. **chip 胶囊输入**：编辑卡里标签框变成胶囊盒，回车/逗号/半角空格都提交一颗；胶囊带 `#` 带 ×；空输入退格删最后一颗；手打 `#` 会被剥掉。落库仍是不带 `#` 的纯文本数组。
2. **等高+折叠**：grid 行内 stretch 对齐，正文超约 4 行（118px）截断并给「展开/收起」，短正文不出按钮；搜索搜的是数据不是 DOM，折叠不影响命中；手机单栏同样生效。没引入任何库。
3. **标签可点筛选**：点卡上任一标签即筛选，再点同标签或点工具区「清除」取消；与分级 chip、搜索框是与关系。games.html 本体做的，游客和后台行为一致。
4. **联想+相似提醒**：打字即下拉已有标签（全部卡片 tags 汇总，前缀匹配排前，可键盘选）；提交库里没有的新标签时，若与已有标签只差大小写/空格/全半角或编辑距离 ≤1（≥4 字放宽到 2），提示「已有相近标签：#XX，要用它吗？」——【用它】【保留】两个按钮，不强制。验收现场她打出的「#逗机系列」脏数据就是这条防的东西。
5. **稳定 id + created_at**：`q-日期-随机`，创建时生成、改标题不变；43 张老卡已回填（`created_at` 回填为迁移时刻并带 `created_at_note` 注明）；前端按 `data-qid` 匹配 DOM，服务端保存按 id 去重补发；重名不拦截，点「完成」时若撞名弹「已有同名帖子，确定保存吗？」；默认按 `created_at` 倒序，新卡在前，卡片 meta 行显示 `YYYY-MM-DD`。
