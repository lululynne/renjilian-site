## 六、独立发现：既有标签属性注入（不归因本次增量）

`games.html:83` 的 `escHtml()` 只转义 `&` 和 `<`，但标签又被拼进双引号属性：

```js
data-tag="${escHtml(t)}"
```

在临时内存把 tag 设为：

```text
x"onmouseover="window.__rj_tag_xss=1
```

浏览器解析结果为：

```html
<span class="tag" data-tag="x" onmouseover="window.__rj_tag_xss=1">...</span>
```

这可形成存储型事件属性注入。相同缺陷已存在于 `games.html.bak-xhs-20260729:77,135,313`，所以不是本次“小红书化增量”引入，也没有把它计入本次增量 FAIL 的两个主因。建议另开安全卡：文本节点用 `textContent`，属性值至少完整转义 `& < > " '`，优先避免用 `innerHTML` 拼数据。
