# 第二人称站标

食指与猫爪相碰，粉色爱心在最底层。用于本站站头、浏览器标签及现有网页应用图标；各栏目已有独立标志继续使用。

- `mark.png`：1024×1024透明方形母版。
- `mark-64.png`、`mark-128.png`：站头小尺寸；保留暖棕轮廓与一个接触亮点。
- `favicon-16.png`、`favicon-32.png`：浏览器标签。
- `icon-192.png`、`icon-512.png`：透明普通网页应用图标，purpose=any。
- `maskable-192.png`、`maskable-512.png`：纸色#fbf5e8不透明底；全部原图alpha像素对应的图形放在中心半径37%内，留出标准40%遮罩安全区。
- `apple-180.png`：180×180纸色主屏幕图标。

正式版本：2026-10-25。图形由内置imagegen按已有食指/猫爪/粉心方向重绘，使用第二次简化稿；再作画布居中、尺寸和PNG编码导出，未作像素修补或手工抠底。透明小图的抗锯齿可以为部分透明；四角应为0。制作提示见`PROMPTS.md`。

Web App名称、启动地址、权限与功能不因图标改变。
